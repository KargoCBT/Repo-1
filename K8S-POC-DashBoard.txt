DashBoard setup

STEPS AFTER  CREATING THE K8S CLUSTER:
 
1.INSTALL THE DASHBOARD
kubectl apply -f https://raw.githubusercontent.com/kubernetes/dashboard/v2.7.0/aio/deploy/recommended.yaml
 
2.VERIFY THE DASHBOARD
kubectl get pods -n kubernetes-dashboard
 
3.CREATE ADMIN USER FOR LOGIN
nano dashboard-admin.yaml
 
PASTE IT IN THE FILE 
apiVersion: v1
kind: ServiceAccount
metadata:
  name: admin-user
  namespace: kubernetes-dashboard
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: admin-user
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: cluster-admin
subjects:
- kind: ServiceAccount
  name: admin-user
  namespace: kubernetes-dashboard
 
4.kubectl apply -f dashboard-admin.yaml
 
5.GET THE LOGIN TOKEN
kubectl -n kubernetes-dashboard create token admin-user
 
6.START THE PROXY
kubectl proxy
